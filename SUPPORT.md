# Support and Questions

Thank you for your interest in Bilgin Apps. This document explains how to request help and where to report issues.

## Choose the right channel

| Topic | Where to go |
| --- | --- |
| Reproducible software defect | Open a **Bug report** in the relevant product repository, if you have access. |
| Product improvement or feature idea | Open a **Feature request** in the relevant product repository, if issues are enabled. |
| Engineering work for collaborators | Open a **Technical task** in the relevant repository, if you have permission. |
| Potential security vulnerability | Follow [SECURITY.md](SECURITY.md) and report privately. |
| Contributor behavior or community concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact an organization owner privately. |
| Questions about local setup | Read the product repository's README and CONTRIBUTING guide first. |
| Product customer support | Use the official in-app or website support channel when one is published. |

## Information to include in a technical support issue

- Relevant product and component.
- Expected versus observed behavior.
- Version, platform, and environment, when available.
- Steps to reproduce with **test data only**.
- Redacted logs or screenshots when helpful.

**Never post access tokens, signing keys, passwords, payment details, learner records, children's data, or other personal information.** Do not disclose potential security vulnerabilities in public issues.

## Response expectations

Bilgin Apps does not currently publish a support response-time commitment in this repository. Posting an issue does not guarantee immediate review or a particular resolution date.

For engineering collaboration, see [CONTRIBUTING.md](CONTRIBUTING.md) and the [Development Standards](docs/DEVELOPMENT_STANDARDS.md).
